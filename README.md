# FoodReview
App que muestra reviews de restaurantes. Estaba basada en el wireframe diseñado en clase de apps moviles. Los restaurantes son ficticios y se encuentran almacenados en un JSON.

# Pasos para iniciar el proyecto en local
1. Instalar Expo Go
```
npm install expo
```

2. Clonar el repositorio
```
git clone https://github.com/AFLeonardo/FoodReview.git
cd FoodReview
```

3. Iniciar el servidor
```
npx expo start
```
